## 已确定的产品规则

| 遇到的选择 | 执行规则与原因 |
| --- | --- |
| 队员只想随手分享一段文字 | 「新建」允许不配图。日常分享进入队内动态，训练资料才进入训练归档和训练合集候选。训练分类将旧「基本概念」归并显示为「基本功」。复盘可以保留自己的「随谈」分类。 |
| 链接没有上传封面 | 优先采用用户自选图片，其次取视频平台封面。平台无可用封面时显示缺图状态。收录单条视频时保留所选视频。 |
| 合集撤回，但既有复盘和原图文仍有用 | 对已确认的历史记录，只解除复盘的来源关联并撤回合集，保留原图文、复盘和原有分享状态。验收同时检查队员旧合集直链失效与两篇原文仍可读。复盘互相关联暂缓。 |
| 私人记录、允许队员阅读和出现在动态 | 「想和写」是新建入口。新复盘默认仅本人可见，首次改为队内可读时，发布到动态默认未勾选。队内可读即可留言，只有分发到动态的复盘才展示留言动态。作者撤回阅读权后，旧留言入口失效。 |
| 谁能修改、删除或导出 | 作者在复盘右上角使用编辑、删除图标，删除前确认。队员可回复自己或队友、删除自己的留言，原留言删除后保留回复。已发布公告开放讨论，私密复盘和公告草稿不开讨论。暂停期间停止导出本人资料。 |
| 网络中断或别人先删了原留言 | 同一阅读权限下，原留言消失时保留已输入的回复，由队员决定是否取消回复。删除回执丢失时用原操作标识核对结果。重新开放阅读权后，旧讨论不会重新出现。 |

## 验证证据与未结事项

- **数据库**。最终迁移在正式备份的隔离副本上演练，原有 46 张表逐表对比，完整性和外键检查通过。正式库复核迁移 0028、留言表和两项撤回触发器。
- **编译产物与合成账号**。最终集成测试 615 项通过，2 项按条件跳过，编译后的 Worker 测试 8 项通过。Chrome 和 WebKit 在 390px、1280px 用两个独立账号验证留言、回复、删除、动态定位、撤权和回执丢失重试。可从[服务端用例](../tests/integration/reader-discussions.test.mjs)、[阅读页适配](../tests/integration/workspace-reader-discussion.test.mjs)和[Worker 用例](../tests/standalone/staging-worker.test.mjs)重跑。
- **正式站**。登录账号在两档宽度下检查了现有复盘、已发布公告、留言接口和作者图标，并取消删除。此次线上检查的业务写入次数为零。正式账号本人重新登录、真实手机无 VPN 的响应时间和系统读屏仍需各自的实测结果。
- **登录支持**。遇到“账号无权访问”时，分别核对成员状态、身份绑定及对应时间的 Access 登录结果。一例现有成员的记录显示邮箱验证码阶段被拒，账号与队籍均有效。日志没有给出验证码拒绝的具体原因，等待本人用最新验证码重试。公开记录只保留排障方法与结论。

## 怎样复核两个容易混淆的操作

- **复盘留言和动态**。作者保存一篇队内可读、未勾选发布动态的复盘，队员进入阅读页留言。两人都应在阅读页看见这条留言，在动态中都找不到它。另建一篇已分发的复盘作对照，从动态点一条回复应定位到该回复。再把复盘改回私密，用队员的旧链接复查。
- **撤回合集和删除原文**。在隔离环境中，用已存在的图文建合集并从复盘关联。撤回合集、解除该关联后，用队员旧链接打开合集，再分别重开复盘与原图文。核对旧合集不可读、复盘不再显示该来源、原有两篇内容仍按各自权限打开。线上定向修复的复验只读已有记录。
